Validation

Is the data right, is the index stable, and does it measure what it claims to?

1. Cross-source checks

Every component is built from raw play-by-play by this project’s own code. To make sure that code reads the events correctly, the counts were compared with two independent sources.

2. Tracking-data validation (Tier 2)

The design calls for checking the play-by-play proxies against NBA player-tracking data (2013-14+): for example, whether excess free-throw rate tracks free throws that did not come from drives, and whether shot-making above expected tracks efficiency on tightly-contested and pull-up shots. Tracking data was never an input to the index; it’s corroborating evidence only.

3. Year-to-year stability

If the index measures a real playing style, a player’s rating this season should predict next season’s. Pure noise would correlate near zero.

EHI is highly persistent (r = 0.74). Self-creation and shot difficulty, essentially a player’s role and shot diet, are the stickiest components. The perimeter and-one rate is the noisiest, which is why it carries the smallest weight.

4. Predictive validation: the 2021-22 rule change

The strongest test of a “whistle” measure is whether it predicts what happens when the league takes the whistle away. Players with higher pre-2021 Whistle Scores lost 0.38 points of true shooting per standard deviation after the crackdown (p = 0.049), while a placebo rule date shows no effect. Full analysis on the Rule Change page.

Bugs caught by these checks (now fixed):

  • Intentional fouls inflated the free-throw rates of elite free-throw shooters (fouled on purpose late in games) and poor ones (hack-a-big). Now only shooting-foul free throws count.
  • “And-ones on jumpers” as a share flagged pure spot-up shooters as foul-baiters. It’s now a rate per perimeter attempt.
  • Shrinkage priors were briefly distorted by tiny samples, producing |z| > 8 outliers. They’re now fit on reliable samples only.
  • Shot-chart joins, the 2012-13 missing games, and heave logging changes were all caught during the data audit, before any metric was built.

Analysis by Rob Kirby · Data: NBA play-by-play & shot charts (shufinskiy/nba_data), pbpstats.com, Basketball Reference
