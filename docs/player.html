Player Search

Look up any qualifying scorer and see their Ethical Hooper Index season by season

Type a name (autocomplete suggests matches). Every regular-season and playoff season in which the player qualified as a scorer is shown: 1,000+ minutes (150+ in the playoffs) and 12+ field-goal attempts per 36 minutes. 50 = an average qualifying scorer that season. Higher is cleaner, more skill-driven scoring.

ps = transpose(ps_raw)
car = transpose(car_raw)
names = Array.from(new Set(ps.map(d => d.player))).sort()
viewof query = Inputs.text({label: "Player", placeholder: "e.g. Steve Nash", value: "Steve Nash",
                            datalist: names, width: 320, autocomplete: "off"})
viewof showPO = Inputs.toggle({label: "Show playoff seasons", value: true})
match = names.find(n => n.toLowerCase() === query.trim().toLowerCase())
  ?? names.find(n => n.toLowerCase().includes(query.trim().toLowerCase()))
rows = match ? ps.filter(d => d.player === match) : []
rs = rows.filter(d => d.type === "RS")
po = rows.filter(d => d.type === "PO")
crec = rows.length ? car.find(c => c.personId === rows[0].personId) : undefined
seasonLabel = y => `${y}-${String((y + 1) % 100).padStart(2, "0")}`
summary = {
  if (!query.trim()) return html`<p class="small-note">Start typing a player's name.</p>`;
  if (!match) return html`<p><strong>No qualifying seasons found for "${query}".</strong> Only seasons with 1,000+ minutes and 12+ FGA per 36 are rated. Check the spelling, or try another player.</p>`;
  const avg = d3.mean(rs, d => d.ehi);
  const careerLine = crec
    ? html`<strong>Career EHI ${crec.career_ehi.toFixed(1)}</strong> · ranked <strong>#${crec.rank} of ${n_careers}</strong> qualifying careers · peak 3-season EHI ${crec.peak3 ?? "n/a"} · career archetype: <strong>${crec.archetype}</strong>`
    : html`Fewer than 4 qualifying regular seasons, so not in the career rankings${rs.length ? html` · average EHI across ${rs.length} qualifying season${rs.length > 1 ? "s" : ""}: <strong>${avg.toFixed(1)}</strong>` : ""}.`;
  return html`<div class="definition"><div style="font-size:1.35rem;font-weight:700">${match}</div>
    <div>${rs.length} qualifying regular season${rs.length === 1 ? "" : "s"}${po.length ? `, ${po.length} qualifying playoff run${po.length === 1 ? "" : "s"}` : ""}</div>
    <div style="margin-top:.4rem">${careerLine}</div></div>`;
}

"+" : ""}${d.skill.toFixed(2)} SD · Whistle ${d.whistle >= 0 ? "+" : ""}${d.whistle.toFixed(2)} SD\n${d.mp.toLocaleString()} min · ${d.fga.toLocaleString()} FGA`}))
  ]
}) : html``

table = match ? Inputs.table((showPO ? rows : rs).map(d => ({
    Season: seasonLabel(d.yr), Type: d.type === "PO" ? "Playoffs" : "Regular", Team: d.team,
    EHI: d.ehi, Skill: d.skill, Whistle: d.whistle, Archetype: d.archetype, Minutes: d.mp, FGA: d.fga})),
  {sort: "Season", rows: 30, layout: "auto",
   format: {EHI: x => x.toFixed(1), Skill: x => (x >= 0 ? "+" : "") + x.toFixed(2), Whistle: x => (x >= 0 ? "+" : "") + x.toFixed(2)}}) : html``

How to read it. Skill Score blends shot-making above expected, self-creation, shot difficulty and clean footwork. Whistle Score blends excess free throws, three-point fouls drawn, free-throw share of points and perimeter and-ones. Both are in standard deviations versus that season’s qualifying scorers. See Methodology. This is a stylistic measure of how a player scores, not a judgment of the person.
